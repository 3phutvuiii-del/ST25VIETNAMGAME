# Dice — 15/10/2026

Added a fourth game to `/casino.html`, using the existing server-side Lúa wallet flow, persisted round IDs, authenticated Steam sessions and uncertain-transaction blocking.

The initial version is roll-under/over because the requested dice variant was unspecified. No answer to the variant question had arrived when implementation proceeded. This is not Tài Xỉu or Bầu Cua.

## Rules

- Roll: 0.00–99.99, generated by Node `crypto.randomInt(10000)` on the server.
- Bet: 1–500 integer Lúa. Target: integer 5–95.
- Under: roll strictly below the target. Over: roll at or above the target; equality wins over.
- Payout, including original stake: `floor(amount * 97 / chancePercent)` when won; zero otherwise. Thus a target of 50 pays 19 Lúa for a winning 10-Lúa roll.
- Expected return before rounding: 97%. Whole-Lúa rounding lowers actual return, especially for small bets. Win chance and actual winning payout are displayed before play.
- Request choice uses `under:50` or `over:50`. Client-provided result/payout fields are not used.
